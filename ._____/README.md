# Casos de uso
En la siguiente lista se muestran los modulos de la pagina web, 
a su vez, la lista acciones que debe abarcar cada uno.
## Rol admin
1. Gestión de docentes
  Crear docente
  Editar docente
  Eliminar docente
  Consultar listado de docentes
  Buscar/filtrar docentes
  Ver detalle de docente
2. Asignaturas
  Crear asignatura
  Editar asignatura
  Eliminar asignatura
  Consultar listado de asignaturas
3. Cursos (relacion asignatura-docente)
  Asignar asignatura a docente
  Cambiar docente asignado
  Quitar asignación de docente
  Ver asignaturas por docente
4. Actividades académicas
  Consultar actividades de docentes
  Filtrar actividades por docente
  Ver detalle de actividad
5. Supervisión de asistencia
  Registrar asistencia de docente
  Modificar asistencia
  Consultar asistencia por docente
  Filtrar asistencia por fecha
  Detectar inasistencias

## Rol docente
1. Cursos (relacion asignatura-docente)
  Consultar mis asignaturas
  Ver detalle de asignatura
2. Actividades académicas
  Crear actividad académica
  Editar actividad propia
  Eliminar actividad propia
  Consultar mis actividades
  Ver detalle de actividad
4. Asistencia
  Registrar asistencia (si es autogestionada)
  Consultar historial de asistencia
  Ver estado de asistencia
