# Instrucciones para ejecutar el proyecto
1. Clonar el proyecto en dentro de la carpeta htdocs de xampp (la ruta deberia quedar C:\xampp\htdocs\gestion-docentes-web)
2. En la carpeta "database" ejecutar los scripts para crear las tablas y registros de prueba en MariaDB (myphpadmin).
3. Asegurar que el servidor de bases y servidor web (apache) esté corriendo en el puerto y credenciales especificadas.
4. Ir a la ruta /localhost/gestion-docentes-web para ir a la ventana del login
5. Probar los flujos de admin y docente. 
    Rol administrador: 
        Cedula: 0100000001
        Contraseña: admin1234
    Rol docente:
        Cedula: 0101234567 (u otra del 5 docentes insertados)
        Contraseña: docente123
